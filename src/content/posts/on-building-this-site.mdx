This file exists to prove the pipeline works. It is marked `draft: true`, so it
shows up while you are running `npm run dev` and disappears from the built site.

Writing a post means adding an `.mdx` file next to this one. The front matter at
the top supplies the title, the date, and the summary that appears on the index.
Everything below it is the post.

## Headings work

So do lists:

- Ordinary markdown, all of it
- Links, quotes, code, images
- React components too, if a post ever needs one

> Pull quotes get the editorial treatment — hairline rule, larger measure, and
> the display face.
